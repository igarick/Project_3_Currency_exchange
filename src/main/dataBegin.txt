1. Открой окно базы данных
Ты уже на нужном экране (где identifier.sqlite), теперь:

👉 Если окна "Database" нет:
Перейди в меню: View → Tool Windows → Database

🧱 2. Как создать таблицу
Способ 1: через GUI (удобно новичкам)
Правый клик по твоей базе identifier.sqlite → New → Table

В появившемся окне укажи:

Имя таблицы (например, products)

Столбцы: id INTEGER PRIMARY KEY, name TEXT, price REAL, и т.п.

Нажми Execute (или Ctrl+Enter)

Способ 2: через SQL-запрос
Правый клик по identifier.sqlite → New → Query Console

В открывшемся окне напиши, например:

sql
Копировать
Редактировать
CREATE TABLE products (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    price REAL
);
Нажми Ctrl+Enter (или правый клик → Execute)

📥 3. Как вставить данные
В той же консоли:

sql
Копировать
Редактировать
INSERT INTO products (name, price) VALUES ('Notebook', 15.5);
INSERT INTO products (name, price) VALUES ('Pen', 2.99);
И снова Ctrl+Enter.

🔍 4. Как просматривать данные
В той же консоли:

sql
Копировать
Редактировать
SELECT * FROM products;
Результат отобразится ниже в табличке.

📁 5. Как посмотреть структуру таблицы
Просто нажми на identifier.sqlite → раскрой список таблиц → правый клик по products → Jump to Data — откроется редактор данных.
